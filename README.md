# OpenBVE Jubilee Line ATO System

A C# Automatic Train Operation (ATO) system developed for the OpenBVE Jubilee Line simulator.

## Features
- Automatic acceleration
- Automatic braking
- Station stopping
- Overspeed protection
- Safety system integration

## Route Coverage
Stratford to West Hampstead
Approx. 15 km

## Technologies Used
- C#
- Visual Studio
- OpenBVE

## Purpose
Personal project created to explore railway signalling, train control systems and rail operations.
